# Galaxy-v2

**Genesis** is an interactive, space-themed visual experiment featuring an orbit-style 3D scene. Drag to orbit, scroll to zoom, and double-tap to reset the view.

## Open locally

No package installation is required. Open `index.html` in a modern browser, or serve it locally:

    python -m http.server 8000

Visit http://localhost:8000.

## Interaction notes

When modifying the visualisation, preserve its touch and pointer controls and keep a clear way to return the camera to its starting position.
