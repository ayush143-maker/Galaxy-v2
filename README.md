# Galaxy-v2

**Genesis** is an interactive, space-themed visual experiment featuring an orbit-style 3D scene. The experience is contained in the top-level `index.html`, which is the page to open. Drag to orbit the scene, scroll to zoom, and double-tap to reset the view.

## Open locally

No package installation is required. Open `index.html` in a modern browser, or, from the repository directory, serve the folder with:

    python -m http.server 8000

Then visit http://localhost:8000.

## Interaction notes

When modifying the visualisation, preserve its touch and pointer controls and keep a clear way to return the camera to its starting position.
