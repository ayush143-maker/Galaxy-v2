# Galaxy-v2

**Genesis** is an interactive, space-themed visual experiment featuring an orbit-style 3D scene. The experience is contained in the top-level `index.html`.

## Open and review locally

No package installation is required. Open `index.html` in a browser, or serve the folder from the repository directory:

    python -m http.server 8000

Then visit http://localhost:8000. After a visual change, check that dragging orbits the scene, scrolling zooms, and double-tapping resets the view. Preserve the touch and pointer controls and a clear way to return the camera to its starting position.

No hosting provider or provider-specific deployment steps are documented. The page can be served as static content; no additional deployment configuration is described.
